# Cocktail Bar Cat — 调酒师喵助手

> 不止告诉你一杯酒怎么调，还讲清它从哪来、能怎么改。调酒师喵把177款配方、老酒谱与有意思的小店酒单串成灵感：帮你推荐、创作、排酒单、算成本，也给家里那半瓶金酒安排新玩法。经典有出处，新酒有根；吧台前的风雅，吧台后的算盘，一只喵都管。

吧台前最难的，从来不是摇好一杯酒，而是下一句：客人说『随便』，新酒单还空着一杯，家里冰箱只剩半瓶金酒，老板又想知道这杯到底赚不赚钱。调酒师喵就是为这些时刻来的。

它先给答案，再给来路。经典配方照着调，也能按心情、甜度和手边有的材料排出几条路线；想改味道，就回到早期酒谱里找这杯的骨架，一次只动一个变量，先做半杯对照，喝过再说好不好。查得到的出处讲得清版次和证据，查不到的传说就老实说没核过——经典有出处，新酒才有根。

一张酒单也能从头陪到尾：主题、顺序、经典锚点、原创特调和独立的无酒精路线，一直到每杯材料成本与建议售价。真实进价只留在你自己的本机副本，公开版用空模板和可复算的演示价格，不冒充市场行情。家里那半瓶也不浪费：两瓶怎么拼、下一瓶买什么、没有摇酒壶先做半杯，都给得出做法。

它不替你喝酒，也不替你拍板。史料有缺口会标出来，新配方一律标着待实饮；不鼓励过量、不点火饮用，不给未成年人推荐酒精；客户偏好和经营记录不离开本机。剩下的，交给吧台前那句『先试试这杯』。

## 使用案例

| 场景 | 示例问法 | 会得到什么 |
|------|----------|------------|
| 门店/家饮推荐 | 客人心情不好、不想喝甜的，推荐并给一句话术 | 经典/公开酒单/微改编/原创/替代无酒精五路线，统一甜度与安全条件 |
| 原创主题酒单 | 万变不离其宗，从老酒谱选骨架设计夏季酒单 | 已核历史锚点或明确结构分析，一处变化、半杯试验与待实饮状态 |
| 历史查询 | 马提尼旧酒谱和今天差在哪？给原文、中文和版次 | 文献记录与归属争议分开，原单位保留，不冒充全球最早 |
| 家庭微创新 | 两瓶金酒，给金菲士三个独立改法 | 骨架不动，一次只改一处，明确预期与风险 |
| 家庭买酒 | 我有金酒和干味美思，下一瓶买什么？ | 当前配方的新增可做与合成价格下的计算，不承诺真实市场性价比 |
| 吧台灵感 | MIXY BAR这杯现在还在吗？ | 有日期的快照与实时月龄；换季店只给思路，提示核当日酒单 |
| 成本教学 | 按公开合成价格算一杯成本，目标毛利由我指定 | `cost/(1-target_margin)`，说明只是材料毛利，非市场报价/经营利润 |
| 空业务运营 | 库存预警/本周销量 | 默认提示暂无数据，不虚构库存、营收或排行榜 |
| 使用反馈 | 我有个建议：怎么老推甜的？ | 先完成任务，再给脱敏≤10行可复制文本，不发送、不上报 |

示例没有真实客户、销量、营收或固定采购价格；私人常客一律用「这位客人/常客A」等称谓，并不公开偏好与过敏信息。

## 公开数据、隐私与安全

- 公开默认**空业务模板+合成计算价格**，消费、销售、库存、采购及价格字段都不是市场行情；无数据不报营收、榜单、库存天数或采购金额。
- **不得上传客户偏好、过敏信息、联系方式或经营记录**，不附带聊天全文、画像或使用频次；匿名化称谓不能把经营记录变成公开知识。
- 查询脚本只读本地文件并打印，不联网、不写盘、不自动学习、上报或同步。宿主模型/平台如何处理对话及第三方安装CLI如何联网与遥测，依其独立政策，不由本技能代作保证。
- 本机授权写入是宿主工具执行的独立行为，私有副本不纳入公开发版；更新先备份，公开包不覆盖私有目录。
- 第三方公开酒单里的消费价格是**带日期与出处的来源知识**，不是本技能采购价/合成售价或现在市场行情；快照不保证现售，古书证据不按现代酒单月龄过期。
- 不给未成年人推荐酒精，不以饮酒治疗情绪/疾病，不鼓励醉酒；驾驶、孕期等先核零酒精标签，不作医疗保证；不点火饮用，蛋奶坚果提示过敏、巴氏杀菌与冷链。
